데일리 잉글리시 사용 방법

데일리 잉글리시 웹 앱을 탐색하고 학습 경험을 극대화하는 방법을 알아보세요.

01

매뉴얼 목차

1. 이용약관

이용약관 및 기기별 확인 사항 이해하기.

2. 메인 페이지

홈 화면 탐색, 세트 선택 및 하루 세션 시작하기.

3. 표현 화면

표현이 어떻게 표시되는지, 예문과 발음 안내.

4. 번역 토글

한국어 번역을 표시하거나 숨겨 암기를 테스트하기.

5. 탐색

세트 내에서 표현을 앞뒤로 이동하기.

6. 즐겨찾기

다시 보고 싶은 표현을 저장하고 즐겨찾기 목록 확인하기.

7. 진도 및 기록

완료된 세트를 추적하고 학습 기록 확인하기.
