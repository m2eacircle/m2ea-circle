Section 3

Leçon de Test et Examen du Conseil

Commencer un Test de Leçon :

1. Sélectionner un Sujet
Lorsque vous cliquez sur le sujet d'une leçon, vous pouvez commencer un test après avoir sélectionné un thème.

2. Option Mode Étude
Si vous cochez le 'Mode Étude', il n'y a pas de limite de temps.

3. Nombre de Questions
Entrez le nombre de questions que vous souhaitez résoudre, ou commencez simplement le test pour un test complet. Si vous entrez un nombre, l'application web de la Banque de Tests en Hygiène Dentaire fournira des questions correspondant au nombre que vous avez entré, et vous pouvez optionnellement passer à la question suivante correspondant au nombre que vous avez entré.

Commencer un Test d'Examen du Conseil :

Structure de l'Examen du Conseil
Lorsque vous cliquez sur un sujet d'Examen du Conseil, vous pouvez commencer un test de la même manière que le sujet de la leçon. La seule différence est que l'Examen du Conseil a deux ensembles pour chaque thème :

  1. Questions Normales — Questions de test standard
  2. Questions d'Étude de Cas — Questions basées sur des scénarios cliniques

Note : Les captures d'écran seront ajoutées ultérieurement.
