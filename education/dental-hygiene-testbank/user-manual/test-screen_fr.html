Section 4

Écran de Test

Fonctionnalités de l'Écran de Test :

1. Minuteur
Chaque question a une limite de 70 secondes. Si vous entrez 3 questions pour le test, une limite totale de 210 secondes sera comptée.

2. Suivi de Progression
Vous pouvez vérifier la Progression du Test (numéros de questions sélectionnées) et la Progression du Thème (total des questions du thème).

3. Affichage du Sujet et du Thème
Vous pouvez vérifier le Sujet et le Thème sélectionnés.

4. Pause et Drapeau
Vous pouvez mettre en pause le processus de test ou marquer la question actuelle.

5. Copier la Question
Vous pouvez copier la question et les 4 réponses multiples.

6. Sélectionner une Réponse
Choisissez votre réponse parmi les options à choix multiples.

7. Soumettre la Réponse
Soumettez votre réponse pour le résultat du test.

8. Vérifier les Résultats
Après avoir soumis votre réponse, vous pouvez vérifier les résultats du test. Si vous souhaitez connaître des informations détaillées ou une explication, vous pouvez cliquer sur l'icône IA pour les détails.

9. Assistance IA
La Banque de Tests en Hygiène Dentaire enverra la question et les réponses multiples au site Web IA sélectionné, mais si elle ne peut pas être transférée au site Web IA en raison de la sécurité, vous pouvez copier et coller sur le site Web IA.

10. Continuer le Test
Après confirmation, cliquez sur le bouton Question Suivante pour continuer le test.
