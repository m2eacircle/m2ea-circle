Section 9

Mode Étude

Utiliser le Mode Étude :

1. Activer depuis la Sélection de Sujet
Vous pouvez sélectionner le Mode Étude depuis l'écran de sélection de sujet.

2. Activer depuis la Sélection de Thème
Ou vous pouvez sélectionner le Mode Étude depuis l'écran de sélection de thème.

3. Pas de Limite de Temps
En Mode Étude, il n'y a pas de limite de temps, vous permettant d'apprendre à votre propre rythme sans pression.

Le Mode Étude est parfait pour réviser le matériel en profondeur et comprendre les concepts sans le stress d'un minuteur.

Note : Les captures d'écran seront ajoutées ultérieurement.
