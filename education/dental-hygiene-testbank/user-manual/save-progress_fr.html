Section 7

Sauvegarder la Progression

Sauvegarder Votre Progression :

1. Sauvegarder depuis l'Écran de Pause
Si vous souhaitez sauvegarder la progression actuelle et souhaitez tester ou étudier plus tard, vous pouvez cliquer sur le bouton Sauvegarder la Progression depuis l'écran de pause.

2. Reprendre le Test Sauvegardé
Lorsque vous accédez à nouveau à l'application web Hygiène Dentaire, vous pouvez reprendre le test sauvegardé là où vous l'avez laissé.

Note : Votre progression est sauvegardée localement sur votre appareil uniquement. Différents appareils auront un suivi de progression séparé.
