섹션 3

레슨 테스트 및 국가고시

레슨 테스트 시작:

1. 주제 선택
레슨 주제를 클릭하면 테마를 선택한 후 테스트를 시작할 수 있습니다.

2. 학습 모드 옵션
'학습 모드'를 선택하면 시간 제한이 없습니다.

3. 문제 수
풀고 싶은 문제 수를 입력하거나, 전체 테스트를 위해 그냥 테스트를 시작하세요. 숫자를 입력하면 치과위생사 시험 문제은행 웹 앱이 입력한 숫자에 맞는 문제를 제공하며, 선택적으로 입력한 숫자에 해당하는 다음 문제로 넘어갈 수 있습니다.

국가고시 시작:

국가고시 구성
국가고시 주제를 클릭하면 레슨 주제와 동일한 방식으로 테스트를 시작할 수 있습니다. 차이점은 국가고시에는 각 테마에 두 가지 세트가 있다는 것입니다:

  1. 일반 문제 — 표준 테스트 문제
  2. 사례 연구 문제 — 임상 시나리오 기반 문제
이전: 메인 페이지 다음: 테스트 화면
