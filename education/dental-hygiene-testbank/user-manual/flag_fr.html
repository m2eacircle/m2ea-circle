Drapeau

Marquer les Questions :

1. Marquer Pendant le Test
Pendant le test, vous pouvez marquer la question du test pour révision ultérieure.

2. Marquer depuis l'Écran de Pause
Sur l'écran de pause, vous pouvez également marquer la question du test.

3. Vérifier les Questions Marquées
Vous pouvez vérifier les numéros de questions marquées et les réviser.

4. Tester et Réviser
Vous pouvez tester et réviser spécifiquement les questions marquées pour vous concentrer sur les éléments difficiles.
