메인 페이지

메인 페이지 기능:

1. m2ea Circle 홈 페이지 접속
m2ea Circle 홈 페이지는 https://www.m2eacircle.com/에서 접속할 수 있습니다.

2. 학습 진도 요약 확인
모든 주제의 학습 진도 개요를 확인하세요.

3. 테스트 시작
각 과목의 주제를 클릭하여 테스트를 시작하세요.

4. 테스트 중 진도 저장
테스트 중 언제든지 진도를 저장할 수 있습니다.

5. 진도 및 기록 상세 확인
성취도 및 과거 테스트에 대한 자세한 정보를 확인하세요.

6. 이용약관 확인
언제든지 이용약관에 접속하여 확인하세요.
